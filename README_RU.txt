EROXVU RP MOBILE — ОБЛАЧНАЯ СБОРКА APK

Это исходный Android-проект. Сам APK в архив не включён: его соберёт GitHub Actions в облаке.
Приложение показывает адрес 188.127.241.74:2663, сообщает, что онлайн/статус/сайт неизвестны,
и копирует IP. Кнопка «Играть» пока объясняет, что нужен совместимый мобильный SA-MP клиент.
Приложение НЕ содержит GTA San Andreas или игровой клиент и не подключается к серверу.

СБОРКА С ТЕЛЕФОНА:
1. Открой github.com в браузере и войди в аккаунт.
2. Создай новый публичный или приватный репозиторий, например Eroxvu-RP-Mobile.
3. Распакуй этот ZIP на телефоне (Файлы → архив → Извлечь).
4. В репозитории нажми Add file → Upload files и загрузи ВСЕ файлы и папки из распакованного проекта,
   включая скрытую папку .github. Если Android/браузер не показывает .github, включи показ скрытых файлов.
5. Нажми Commit changes.
6. Открой вкладку Actions. Дождись завершения workflow "Build Eroxvu RP APK".
7. Открой успешный запуск workflow, найди Artifacts и скачай Eroxvu-RP-Mobile-APK.
8. Распакуй скачанный artifact ZIP — внутри будет app-debug.apk. Открой APK и разреши установку
   из этого источника, если Android спросит.

Если GitHub не показывает Actions: открой Settings → Actions → General и разреши actions для репозитория.
Не делись паролем или кодами входа с кем-либо.
